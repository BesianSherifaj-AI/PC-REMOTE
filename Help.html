PC Remote

A browser companion for your Windows PC, phone, tablet, or spare Android touchscreen.

Open your dashboard

Use Desktop → MAIC PC → Start or Open Dashboard. Both start the server if needed and open its current local address. Copy that address to a browser on your phone/tablet. The address is also saved in .runtime/server.url; it is different for each PC.

Windows starts the server quietly after sign-in, waiting up to 90 seconds for the chosen Wi-Fi/Ethernet connection. Keep the PC awake and online. Stop shows confirmation and stops only this project's processes.

Use the pages

Choose a page in the sidebar on desktop and tablets, or the bottom navigation on phones. Use Full screen in the header to expand the page when your browser supports it.

  • Home: PC volume/microphone mute, media controls, hardware usage, websites, calculator, and timer.
  • Apps: Search installed programs, save favourites, and open or switch to their Windows windows.
  • Desktop: Connect the live screen. In Control, one finger operates Windows and two fingers pan/pinch-zoom without changing modes. Keyboard types into the focused Windows field. Pan only enables one-finger navigation; View only blocks Windows input. Full screen expands the dashboard; Expand desktop shows just the viewer. If native fullscreen does not work, Fill browser immediately expands the viewer inside the browser. Exit expanded view restores the dashboard. Safari's own bars can remain in a normal tab.
  • Chat: Choose a loaded LM Studio model in the model bar. Expand Model settings to open LM Studio, start its API, or load an installed model. Type and press Send, or Ctrl+Enter / Cmd+Enter; Enter alone adds a new line. Stop cancels generation and New chat clears the conversation and attachments. Use Image with a vision-capable model.
  • ComfyUI: View the PC service on port 8010, its queue, images, and video previews. Nothing submits or interrupts generation.

Use it like an app

iPhone: open your secure dashboard address in Safari, tap Share → Add to Home Screen, enable Open as Web App if offered, then tap Add. Open the PC Remote icon for a view without Safari's address bar. See Apple's instructions.

PC browser: Full screen uses native browser fullscreen where supported; Esc exits it. Expand desktop focuses the viewer. A Home Screen installation may need its own connection request and local-PC approval; adding the icon never grants access automatically. The PC still needs to remain online.

Chat with voice

Speak records on this device and uses optional PC Whisper dictation to insert editable text. Read reply plays optional PC-generated speech. Expand Voice settings for the voice, speed, language, and Live voice controls. Live voice listens for a pause, sends your words, reads the reply, then listens again; it takes turns rather than listening and speaking simultaneously. Stop ends the loop. Both speech components must be installed first. Recording requires HTTPS and microphone permission; typed chat always remains available.

Approve your device

On a trusted LAN, check your device's Wi-Fi IPv4 address, then run Approve-MAIC.ps1 -Address '192.168.1.50' on the PC, replacing the example. LAN approvals are IP-based; remove stale approvals when an address changes.

Away from home: first complete the optional Tailscale HTTPS setup in the README. Expand Home → Connect from anywhere, open the secure address, request connection, then approve the matching code from this PC's local dashboard. Bookmark that secure address and revoke lost devices from the PC. No code needs to be shared with anyone else.

If something stops working

Refresh after dashboard updates. If the PC's LAN address changes, use Stop then Start and copy the new address. Guest Wi-Fi may isolate devices. Windows Firewall must allow the server on your trusted private network. The PC microphone mute control affects the PC's microphone; it does not turn your tablet into a PC microphone.

Errors are saved locally under .runtime. Do not publish that folder. Desktop access needs Windows to remain signed in; no Android installation or OS reset is required.
